# Настройки

Откройте настройки шестерёнкой справа в заголовке окна, через **Tools › Settings** или сочетанием ++ctrl+comma++. Все изменения сохраняются автоматически.

<img class="screenshot" src="../../../assets/screenshots/settings.png" alt="Страница Presets в настройках">

## Пресеты

Пресет разом задаёт все настройки сканирования, конвертации и безопасности. Папки, число потоков, пути к инструментам и тема относятся к вашему компьютеру, поэтому пресеты их не меняют.

| Встроенный пресет | Что он задаёт |
| --- | --- |
| Default | Настройки новой установки |
| Thorough check (40 clips) | 40 фрагментов на фильм и полная проверка; оригиналы сохраняются |
| Exhaustive check (100 clips) | 100 фрагментов на фильм и полная проверка; оригиналы сохраняются |
| Replace originals, keep EL archive | 40 фрагментов, резервная копия слоя улучшения, замена оригиналов после полной проверки, Корзина включена |

**Apply preset…** сначала показывает все настройки, которые изменятся, и отмечает те, при которых можно потерять данные. Можно сохранять и свои пресеты.

## Страницы

| Страница | Что там настраивается |
| --- | --- |
| **General** | Тема, флажки в списке файлов, уведомления |
| **Conversion** | Безопасный режим, Convert to HDR10, обработка FEL, резервная копия слоя улучшения, папка результатов, глубина поиска во вложенных папках, папка временных файлов |
| **Safety** | Уровень проверки, Replace original after verification, Корзина, дополнительный запас свободного места |
| **Analysis** | Число и длина фрагментов, требуемое покрытие сканирования, перцентиль пиковой яркости, порог обнаружения Complex FEL и предполагаемая пиковая яркость |
| **Performance** | Одновременные конвертации, параллельные фрагменты сканирования, приоритет инструментов, автоматическое сканирование, повторное использование сохранённых результатов, медиатека |
| **Watch folder** | Папка, за которой нужно следить и автоматически конвертировать. См. [Папка наблюдения](watch-folder.md). |
| **Native tools** | Состояние инструментов, их установка, свои пути к инструментам |
| **About** | Версия, проверка обновлений, логи, экспорт диагностики |

## Параметры анализа по умолчанию

| Параметр | По умолчанию | Допустимые значения |
| --- | --- | --- |
| Clips per video (фрагментов на видео) | 10 фрагментов | 1–100 |
| Clip length (длина фрагмента) | 1 секунда | 0,1–60 секунд |
| Required scan coverage (требуемое покрытие) | 100% | 1–100% |
| Peak-brightness percentile (перцентиль пиковой яркости) | 100% (самый яркий кадр) | 1–100% |
| Brightness margin (запас яркости) | 50 нит | 0–1000 нит |
| Assumed peak brightness (предполагаемая пиковая яркость) | 1000 нит | Используется, когда в файле нет пригодного MaxCLL |

Меньшие значения ускоряют сканирование, но могут пропустить яркость, которую добавляет слой улучшения. После их изменения сохранённые результаты устаревают — просканируйте или проверьте фильмы ещё раз, чтобы их обновить.

## Где хранятся ваши данные

| Что | Где |
| --- | --- |
| Настройки и ваши пресеты | `%LOCALAPPDATA%\DoViFixer\settings.json` и `presets.json` |
| Медиатека (запомненные фильмы, результаты, история) | `%LOCALAPPDATA%\DoViFixer\library.db` |
| Логи | `%LOCALAPPDATA%\DoViFixer\Logs` |
