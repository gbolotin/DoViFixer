# Папка наблюдения

DoViFixer может следить за папкой, например за папкой загрузок, и сам конвертировать новые фильмы, пока приложение запущено.

## Настройка

1. Откройте **Settings › Watch folder**.
2. В разделе **Folder to watch** нажмите **Browse** и выберите папку.
3. По желанию включите **Watch subfolders too**.
4. По желанию измените **Wait before acting** (по умолчанию 30 секунд).

## Что происходит

1. В папке появляется новый MKV-файл.
2. Приложение ждёт, пока размер файла не перестанет меняться в течение времени ожидания и пока в него не перестанет писать другое приложение. Файл, который ещё копируется, никогда не читается наполовину записанным.
3. Приложение сканирует файл.
4. Если ваши настройки разрешают его конвертировать, фильм попадает в список Media и конвертируется. Остальные файлы в список не попадают, а **Activity** объясняет почему.

Автоматическая конвертация использует ваши настройки Conversion и Safety — точно так же, как кнопка **Convert**. Она никогда не показывает диалогов: если результат уже существует, файл пропускается, а о недостающих инструментах приложение сообщает, а не устанавливает их. Фильмы, которые уже лежали в папке, когда началось наблюдение, не конвертируются.

## Состояние

В строке состояния показано **Watching:** с именем папки, число ожидающих файлов, а во время конвертации — **Auto-converting from** с именем папки. Щелчок по ней открывает настройки Watch folder. В **Activity** такие фильмы отмечены как «Auto-converted».
