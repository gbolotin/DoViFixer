# Резервная копия и восстановление

Слой улучшения — небольшая часть фильма в Profile 7. DoViFixer может сохранить его в файл резервной копии `.dovi` рядом со сконвертированным фильмом. С этой копией оригинальный фильм в Profile 7 можно восстановить в любой момент, а большой оригинал — удалить уже сейчас.

## Резервная копия при конвертации

Включите **Settings › Conversion › Back up enhancement layer**. Тогда при каждой конвертации сохраняется ещё и:

```
Movie - DV P8.1.mkv   ← сконвертированный фильм
Movie.dovi            ← резервная копия слоя улучшения
```

Файл `.dovi` привязан к базовому слою сконвертированного фильма хешем SHA-256, поэтому его нельзя по ошибке восстановить на другой фильм.

## Восстановление в Profile 7

Когда рядом со сконвертированным фильмом лежит его резервная копия `.dovi`, в строке фильма появляется **Restore to DV7**.

1. Нажмите **Restore to DV7** в строке или выберите несколько фильмов и используйте **File › Restore to DV7…**.
2. Просмотрите файлы, которые создаст приложение.
3. Нажмите **Approve and start**.

Восстановленный фильм сохраняется как новый файл; сконвертированный фильм и резервная копия остаются.

## Очистка резервных копий

**Tools › Clean up backups…** находит в папке резервные копии `.dovi` и оригиналы `.bak.dovi_convert`. Вы просматриваете список, и приложение удаляет ровно эти файлы. По умолчанию они отправляются в Корзину.

## Другие случаи

Резервные копии в другой папке, старые копии без манифеста и восстановление в другую папку доступны из командной строки: см. `backup` и `restore` в разделе [Командная строка](../console.md).
