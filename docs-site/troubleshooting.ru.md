# Решение проблем

## Сочетания клавиш

| Клавиши | Действие |
| --- | --- |
| ++f1++ | Открыть эту документацию |
| ++f4++ | Проверить (Inspect) выбранные фильмы |
| ++f5++ | Конвертировать выбранные фильмы |
| ++ctrl+comma++ | Открыть настройки |
| ++ctrl+a++ | Выбрать все фильмы |
| ++delete++ | Убрать выбранные фильмы из списка (файлы на диске остаются) |

## Частые вопросы

??? question "Кнопка Convert неактивна"
    Все выбранные фильмы были бы только пропущены. Обычные причины: фильм не в Profile 7 или это FEL, а параметры FEL в **Settings › Conversion** выключены. В строке каждого фильма написано почему.

??? question "Инструмент не найден или не подходит"
    Выберите **Tools › Check dependencies**. Приложение предложит установить недостающие инструменты. Чтобы использовать свою копию, укажите путь к ней в **Settings › Native tools**. Графическое приложение MediaInfo не подходит — DoViFixer нужен MediaInfo **CLI**.

??? question "Не хватает места на диске"
    Конвертация сначала резервирует временное место. Укажите диск побольше в **Settings › Conversion › Temporary storage folder** или уменьшите число одновременных конвертаций в **Settings › Performance**.

??? question "Выходной файл занят"
    Папку читает другое приложение, часто медиасервер. DoViFixer повторяет попытку, а если не получается, называет приложения, которые держат файл, когда Windows может это сообщить. Закройте их и запустите конвертацию снова.

??? question "Где мой сконвертированный фильм?"
    Рядом с оригиналом, под именем `<имя> - DV P8.1.mkv`, если вы не задали другую **Output folder**. Щёлкните расположение файла в панели подробностей, чтобы открыть папку.

## Activity

Кнопка **Activity** слева в строке состояния показывает, что произошло за этот сеанс: каждый просканированный, сконвертированный или восстановленный фильм, простыми словами. Красный счётчик показывает новые проблемы. Каждую запись можно открыть в Проводнике или скопировать её текст.

## Логи и диагностика

- **Help › Open logs** открывает папку с логами (`%LOCALAPPDATA%\DoViFixer\Logs`).
- **Help › Export diagnostics…** сохраняет ZIP-архив с последними логами и вашими настройками для отчёта об ошибке. Ничего никуда не отправляется. Просмотрите архив, прежде чем им делиться: в нём могут быть пути к файлам и имя пользователя.

## Сообщить о проблеме

Создайте [issue на GitHub](https://github.com/gbolotin/DoViFixer/issues). Опишите, что вы делали, чего ожидали и что произошло, и по возможности приложите ZIP-архив диагностики.
