# Установка

DoViFixer работает в 64-разрядных Windows 10 и Windows 11.

## 1. Установите среду .NET

DoViFixer нужна **.NET 10 Desktop Runtime** (x64).

1. Откройте [страницу загрузки .NET 10](https://dotnet.microsoft.com/download/dotnet/10.0).
2. В разделе **.NET Desktop Runtime** скачайте установщик для Windows **x64**.
3. Запустите установщик.

## 2. Скачайте DoViFixer

1. Откройте [последний выпуск](https://github.com/gbolotin/DoViFixer/releases/latest).
2. Скачайте `DoViFixer.App-X.Y.Z.zip`.
3. Распакуйте его в любую папку, например `C:\Apps\DoViFixer`.
4. Запустите `DoViFixer.App.exe`.

!!! tip "Другие файлы в выпуске"
    `DoViFixer.Console` — версия для командной строки. `DoViFixer.Mcp` позволяет ИИ-ассистенту, например Claude Desktop, работать с DoViFixer. Для настольного приложения нужен только `DoViFixer.App`. См. [Командная строка и ИИ-ассистенты](console.md).

## 3. Дайте приложению установить инструменты

DoViFixer читает и записывает видеофайлы с помощью бесплатных и известных инструментов:

| Инструмент | Для чего он нужен DoViFixer |
| --- | --- |
| FFmpeg и ffprobe | Читать видеопоток и сведения о кадрах |
| MKVToolNix (mkvmerge, mkvextract, mkvpropedit) | Разбирать MKV-файлы и собирать их обратно |
| MediaInfo **CLI** | Читать сведения о HDR и Dolby Vision в файле |
| dovi_tool | Читать и конвертировать метаданные Dolby Vision |

При первом запуске приложение проверяет, есть ли эти инструменты.

<img class="screenshot" src="../../assets/screenshots/dependencies.png" alt="Проверка нужных инструментов при первом запуске">

- Уже установленные инструменты используются как есть.
- Если инструмента нет, приложение показывает точную версию, адрес загрузки и папку назначения. Оно ничего не устанавливает, пока вы не согласитесь.
- Загрузки сверяются с известным хешем SHA-256. Инструменты устанавливаются в ваш профиль пользователя, права администратора не нужны.

!!! note "Примечание"
    Графическое приложение MediaInfo (**GUI**) не подходит. DoViFixer нужна версия MediaInfo для командной строки (**CLI**).

Проверить инструменты ещё раз можно в любой момент через **Tools › Check dependencies**, а указать свои пути к ним — в **Settings › Native tools**.

## Обновления

Версия приложения показана в **Settings › About**. DoViFixer никогда не обновляется сам. Чтобы обновить его, скачайте новый zip-архив и распакуйте его поверх старой папки. Настройки и медиатека хранятся в `%LOCALAPPDATA%\DoViFixer` и сохраняются.

Далее: [Перед конвертацией](before-you-convert.md).
